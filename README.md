# Projeto de Inteligência Artificial - Unidade 1

Este repositório contém os estudos e implementações do projeto de IA.

## Estrutura
- `/data`: Arquivos de dados brutos (locais).
- `/notebooks`: Experimentos e análises no formato Jupyter Notebook.

## Como preparar o ambiente
1. Crie o ambiente virtual: `python -m venv .venv`
2. Ative o ambiente: `.venv\Scripts\activate`
3. Instale as dependências: `pip install pandas numpy scikit-learn jupyter`
